# Changelog

## 0.1.0 alpha · Unreleased

- Browse with horizontal or vertical tabs, pinned tabs, groups, and an
  immersive sidebar that opens at the window edge.
- Keep sessions and site data separate with profiles, private windows,
  and containers. Containers can use HTTP or SOCKS5 proxies.
- Import bookmarks, history, and supported password data. Manage downloads,
  PDFs, and local documents.
- Manage content blocking, site permissions, cookies, and browsing data.
- Store and fill logins with the browser vault, system keyring, or Bitwarden.
  Manage passkeys with supported connectors.
- Use the optional Assistant beside a page and grant individual browser
  functions through the enzUI Agent Center.
- Choose a background-tab memory policy and release caches when tabs are idle.
- Scale large images off the tile workers in the selected WebKit runtime.
